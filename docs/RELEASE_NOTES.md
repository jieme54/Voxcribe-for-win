- Translated the README, release notes, and bundled getting-started guide into English.
- Translated the build and setup script messages into English.

## Installation

1. Download **Voxcribe-Windows-x64.zip** and extract it completely.
2. Open the `Voxcribe` folder and run `Voxcribe.exe`.
3. In settings, install a compatible NVIDIA, AMD, or CPU runtime.
4. Download a model and select your audio source.

Requires Windows 11 x64. .NET is included. Python runtimes and model weights
are installed separately from settings. Internet access is required for those
downloads; transcription runs locally on your computer.

Your settings, runtimes, and downloaded models are stored under
`%LocalAppData%\Voxcribe`. To update, close the application and extract the new
ZIP into a separate folder.
