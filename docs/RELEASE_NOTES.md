# Voxcribe 1.0.0 for Windows

Première publication publique de Voxcribe pour Windows, avec le code source
sous licence MIT et une application prête à lancer.

## Installation

1. Téléchargez **Voxcribe-Windows-x64.zip** et extrayez-le entièrement.
2. Lancez `Voxcribe/Voxcribe.exe`.
3. Dans les paramètres, installez un moteur NVIDIA, AMD compatible ou CPU.
4. Téléchargez un modèle et sélectionnez votre source audio.

Windows 11 x64 est requis. .NET est inclus. Le moteur Python et les modèles
sont téléchargés séparément ; leur installation nécessite Internet et de
l'espace disque. La transcription s'exécute localement.

## Fonctions

- Microphone et autres sources audio Windows.
- Transcription standard et temps réel selon le modèle.
- Import de fichiers audio et vidéo.
- Fenêtre de transcription, copie et insertion du texte.
- Fenêtre toujours visible, zone de notification et raccourci clavier global.
- Interface français / anglais.

Le code source est disponible dans ce dépôt et via les archives « Source code ».
Les modèles et les dépendances conservent leurs propres licences.

## English

Extract **Voxcribe-Windows-x64.zip** and run `Voxcribe/Voxcribe.exe`.
Install a supported NVIDIA, AMD, or CPU runtime from settings, then download

are downloaded separately. Transcription runs locally.
