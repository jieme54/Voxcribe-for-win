# Voxcribe 1.0.0 for Windows

The first public release of Voxcribe for Windows, with MIT-licensed source code
and a ready-to-run application.

## Installation

1. Download **Voxcribe-Windows-x64.zip** and extract it completely.
2. Run `Voxcribe/Voxcribe.exe`.
3. In settings, install a compatible NVIDIA, AMD, or CPU runtime.
4. Download a model and choose your audio source.

Requires Windows 11 x64. .NET is included. The Python runtime and models are
downloaded separately and require Internet access and sufficient disk space.
Transcription runs locally on your computer.

## Features

- Microphone and other Windows audio sources.
- Standard and real-time transcription, depending on the model.
- Audio and video file import.
- Transcript window, text copying, and text insertion.
- Always-on-top overlay, notification area support, and a global shortcut.
- English and French interface options.

Source code is available in this repository and through the **Source code**
archives. Dependencies and model weights retain their own licenses.

**SHA256SUMS.txt** contains the application's ZIP checksum.
